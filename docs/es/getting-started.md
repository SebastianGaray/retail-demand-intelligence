# Primeros pasos

Instala Python 3.12 y `uv`, y luego ejecuta:

```bash
make install
make check
```

Copia `.env.example` como `.env` solo si necesitas modificar la configuración local.

Consulta el [resumen de datos](datasets.md) para conocer las entradas Parquet validadas.
Consulta [datos sintéticos de demostración](demo-data.md) para generar datos locales.
Consulta el [flujo de pronóstico](forecasting.md) para entrenar, evaluar y guardar predicciones.
