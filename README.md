# Retail Demand Intelligence

Python project for reproducible retail demand forecasting and inventory-risk analysis.

The repository currently provides the project foundation: packaging, configuration, quality
checks, tests, documentation, Docker, and CI. Forecasting workflows and user interfaces are not
implemented yet.

## Setup

Requires Python 3.12 or later and [`uv`](https://docs.astral.sh/uv/).

```bash
make install
make check
```
