Project Purpose / Propósito

This project serves as a high-fidelity demonstration of predictive retail analytics. It integrates machine learning with a scalable frontend to visualize store-level demand shifts and inventory risks.

Este proyecto funciona como una demostración de alta fidelidad de analítica predictiva para retail, integrando machine learning con una interfaz escalable.

  • check_circle Optimization of stocking levels through temporal demand forecasting.
  • check_circle Risk mitigation for out-of-stock and over-stock scenarios.

Synthetic Data Notice

All datasets used in this demonstration are **synthetic**. They are generated to mimic real-world retail patterns including seasonality, promotional spikes, and supply chain disruptions. No real customer or proprietary store data is present.

Aviso: Todos los datos son sintéticos y generados para simular patrones reales de retail.

Limitations

  • • Historical window is capped at 24 months.
  • • External macro-economic factors (inflation, etc.) are currently decoupled.
  • • Cold-start scenarios for new products use mean-imputation.
